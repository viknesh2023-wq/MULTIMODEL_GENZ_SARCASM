[SAY]
"Here is our proposed system architecture diagram. This is the complete system
pipeline that drives our application.

Our architecture accepts two parallel inputs: social media text and an optional
meme image.

For the text input, we extract a 768-dimensional contextual representation
using fine-tuned XLM-RoBERTa.

For the visual input, we extract dual visual features: 512 image tokens using
CLIP ViT-B/32, and 1,536 visual-semantic tokens using InternVL3-2B.

To capture emotional undertones, auxiliary classifiers generate 3 sentiment
scores and 28 fine-grained emotion probabilities.

These five sources are concatenated into a unified 2,847-dimensional feature
vector, normalized by a pre-fitted scaler, and classified by our
MultimodalFusionMLP network into Sarcastic or Non-Sarcastic.

Finally, an optional local Llama 3.2 1-Billion model provides natural language
explanations without altering the classifier's predicted labels or probabilities."

[SHOW]
Point your mouse cursor steadily across:
1. Input Layer (Text + Meme Image)
2. Five Feature Extractors (XLM-R, CLIP, InternVL, Sentiment, Emotion)
3. 2,847-D Concatenation Layer
4. Multimodal Fusion MLP Classifier (Linear 2847 -> 1024 -> 512 -> 128 -> 2)
5. Decoupled Llama 3.2 Ollama Explanation Component

[RECOVERY CONTINGENCIES]:
1. If the Ollama explanation service is slow:
   The application automatically switches to our deterministic cognitive reasoner
   fallback (<1 ms). The classifier prediction is completely independent and
   will succeed.
2. If the backend disconnects:
   Check the PowerShell window running 'run_server.py'. It can be restarted
   instantly, and the frontend will automatically reconnect.
